# frontend-vue 重构执行指南

## 目标

- 使用 `Vue 3 + Vite + TypeScript + Vue Router + Pinia + Axios + ECharts` 重建前端
- 严格复用现有后端接口，不新增、不删减业务接口
- 布局参考 `chatgpt.com`，采用“侧边栏 + 聊天区”结构

## 关键交互

- 用户消息使用右侧气泡
- assistant 回复不使用气泡，采用自然文本流
- 聊天区内容居中，左右留白
- 分析进度属于 assistant 回复前的临时处理态
- 分析完成后仅保留一个最终 assistant 结果消息，进度自动收起
- 图表渲染在 assistant 结果消息内部

## 实施顺序

1. 搭建路由、状态管理和 API 封装
2. 完成认证页与登录态恢复
3. 完成侧边栏、会话列表、会话操作
4. 完成聊天消息流和普通聊天
5. 完成分析任务进度、结果消息、图表和重试
6. 联调 CORS、轮询稳定性和构建验证
