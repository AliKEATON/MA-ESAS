# 项目目录结构说明

## 1. 更新原则

本文档以当前仓库实际状态为准，重点反映已经落地的多 Agent 分析链路，而不是旧版单链路实现。

本次更新特别说明：
- `backend/app/agents/` 已经是新版 LangGraph 多 Agent 工作流实现核心目录。
- `backend/app/schemas/agent_protocol.py` 已落地，作为节点间流转协议。
- `backend/app/api/analysis.py`、`backend/app/models/analysis_task.py` 已存在，不能再标注为“待补充”。
- 仓库当前同时存在 `frontend-streamlit/` 与 `frontend-vue/` 两套前端，其中 Vue 版已是更完整的新前端工程。
- `frontend-vue/src/views/`、`frontend-vue/src/components/` 已按当前真实文件名校正，不再沿用旧页面和旧组件命名。
- `node_modules/`、`dist/`、`.venv/`、`__pycache__/`、`.pytest_cache/` 属于生成产物，不作为核心源码维护对象。

---

## 2. 当前整体结构

```text
MA-ESAS-1/
├── backend/                    # FastAPI 后端与 LangGraph 多 Agent 分析链路
├── data/                       # 根目录运行期数据
├── docs/                       # 项目设计与说明文档
├── frontend-streamlit/         # 早期 Streamlit 原型前端
├── frontend-vue/               # 当前 Vue 3 + Vite 前端工程
├── logs/                       # 根目录日志占位目录
├── process/                    # 项目过程记录与临时设计文档
├── 论文报告/                    # 论文相关文档
├── .cursor/                    # Cursor/Codex 辅助配置目录
├── .vscode/                    # VS Code 工作区配置
├── .env                        # 本地开发环境变量
├── .env.example                # 环境变量示例
├── .gitignore                  # Git 忽略规则
├── README.md                   # 项目说明
├── requirements.txt            # 根级 Python 依赖
├── requirements-dev.txt        # 根级开发依赖
└── tmp_*.txt                   # 终端/编码调试产生的临时文件
```

## 9. 与当前多 Agent 新架构的对应关系

当前仓库已经完成以下关键落地：

1. 协议层：`backend/app/schemas/agent_protocol.py`
2. 工作流编排层：`backend/app/agents/workflow.py`
3. Agent 实现层：`backend/app/agents/router_agent.py`、`sql_agent.py`、`rag_agent.py`、`visual_agent.py`、`answer_agent.py`、`master_agent.py`
4. 任务模型层：`backend/app/models/analysis_task.py`
5. 任务接口层：`backend/app/api/analysis.py`
6. 任务服务层：`backend/app/services/analysis_service.py`

因此，项目目录说明应以“新版多 Agent 分析链路已落地”为基准，不再沿用旧文档中“分析接口/任务模型尚未实现”的表述。
