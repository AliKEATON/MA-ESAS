2.融合LLMs和MCP技术的数据分析与知识服务智能体研究与应用
为解决传统时空数据分析中专业软件操作复杂、非结构化需求转化困难以及低效重复性工
作等问题，探索利用大语言模型（LLMs）强大的逻辑推理、多模态输出与指令执行能力，驱动行业智能化转型
的新途径。本研究融合 LLMs 与模型上下文协议（MCP）技术，构建了数据分析与知识服务智能体（DAKSAgent）。该智能体旨在实现用户自然语言指令到专业地理信息系统（GIS）软件工具的自动化映射。测试结果
表明：①MCP作为标准化中间协议，实现了LLMs与GIS专业软件的无缝衔接；②该智能体能够支撑时空数据
的标准化处理、空间分析、专题制图以及辅助决策结果的高效输出；③DAKS-Agent的模块化设计支持动态扩
展第三方数据源与算法库，能有效解决多源异构数据治理、数据价值转化及知识服务精准供给等难题。本研
究提出的 DAKS-Agent框架，为 GIS分析的智能化与普适化应用提供了切实可行的新路径，显著提升了分析
效率和易用性。

4.基于 LLM Agent 的金融智能对话机器人系统构建
近年来，大语言模型的迅猛发展为各行各业带来了革命性的变革，其中基于
大语言模型的知识检索和 Agent 系统在金融行业中的应用尤为引人注目。作为一
个高度依赖人工分析和决策的领域，金融行业对信息的准确性和时效性有着极高
的要求。本研究聚焦于如何充分利用大语言模型及其衍生技术来优化金融企业内
部知识与信息的利用效率这一关键问题，设计并实现了一个基于大语言模型 Agent
的金融问答系统来试图解决这一问题。主要工作包括三个方面：
1. 利用金融企业的内部数据，采用 QLoRA 与 NEFTune 的组合方案对 LLaMA2
模型进行微调。QLoRA 通过优化显存使用效率，使得模型在训练过程中能够处理
更大规模的数据，而 NEFTune 则通过引入噪声来降低过拟合风险。通过这种微调
策略不仅提升了模型的训练效率，还显著增强了其在金融领域任务中的精准性和
表现能力。
2. 设计并实现了一套基于 4R 架构的知识检索系统，基于 RAG 架构对各个环
节进行了升级优化。在 rewrite 环节精准转写用户意图，在 retrieval 环节引入多路
召回机制丰富知识内容，在 rerank 环节综合排序提取有效信息，最终通过 read 环
节生成高质量结果。同时还对 embedding 方法和向量检索技术进行了深入研究与
优化，通过改进文本表示方法和检索算法，成功提升了在处理海量金融业务知识
时的准确性和处理效率。
3. 设计并实现了一套 Agent 系统，支持多个 Agent 实例和系统工具，并与金融
企业内部各业务系统无缝对接。每个 Agent 具备独立功能以满足不同业务需求，同
时集成的系统工具使其能够有效的访问多种数据资源，提供精准的解决方案。该
系统能够高效进行跨系统交互，显著提升问题解决的效率。
基于上述工作，搭建了金融智能对话机器人系统，并已在某金融企业上线部
署并提供服务。

6.面向主题的智能问答机器人对学习过程和学习结果影响的实证研究
智能问答机器人是人工智能技术的典型应用之一，将智能问答机器人应用于教育教学领域受到了越来越多研究者的
关注。本研究以七年级学生为研究对象，通过准实验研究探索了使用面向主题的智能问答机器人和传统搜索引擎辅助学习对学
习过程和学习结果的影响。结果表明，相较于传统搜索引擎，面向主题的智能问答机器人能够更好地帮助学习者进行学习，具
体体现在：在学习过程方面，智能问答机器人能够提升知识检索效率，提高学习者的内部学习动机，减轻网络迷航状态；在学
习结果方面，智能问答机器人能够提升学习者的知识测试成绩。但在紧张 - 压力和努力程度方面，两种辅助学习工具不存在
显著性差异。上述结果验证了面向主题的智能问答机器人在辅助学习方面的潜力与价值。

7.多 Agent 协作的知识推理框架
情报分析的核心任务是从海量数据中提取事件关联并推导因果关系。然而，当前基于大语言模型（LLM）的方法
在处理长文本时，受限于上下文窗口和计算复杂度，难以有效捕捉事件间的因果关联，导致推理能力显著下降，这一现象在
参数规模较小的语言模型中尤为突出。针对这一问题，提出一种多 Agent 协作的知识推理（MAKR）框架。该架构通过增量式
构建实体关系图，显式建模实体间的复杂关联，从而辅助 LLM 实现更精准的因果推理。双塔结构的设计使图模型与语言模型
能够分别独立处理图结构信息和文本信息，并通过融合机制增强模型对长文本中复杂逻辑关系的理解能力。此外，模型在语
言预测任务的基础上，增加了针对图中节点关系的预测任务，进一步优化语义对齐效果。实验结果表明，在有限计算资源条
件下，MAKR 框架在 GDELT 数据集的安全事件分析和 OpenSanctions 数据集的制裁关联分析任务中，事件预测和因果推断的
准确率均显著优于 HetGNN(Heterogeneous Graph Neural Network)、HiGPT 等对比方法，验证了它在计算资源受限的工业场景
实用价值。

8.超越情感分析：从消费者评论中探查酒店服务质量的新思路
在数字经济背景下，在线评论已成为酒店改进服务质量和消费者决策的重要参考。然而，以
往研究多依赖整体评分或粗略的情感分析，难以深入挖掘评论所蕴含的价值信息。本文提出了一种更为精
细化的评论分析方法，从评论文本中提炼设施词、标签词、厌恶词与奖励词等多维度信息。看似中性的设
施词却能呈现顾客对核心接触点的不满，标签词能够提升评论的有用性，厌恶词暴露严重的服务失败，而
奖励词则揭示极端满意体验。基于此，酒店可以在不同情境下采取针对性措施：通过设施词与标签词提升
服务质量，通过厌恶词实现精准服务补救，通过奖励词巩固优势体验将顾客转化为忠实顾客。因此，本文
为酒店实现服务质量升级、服务失败补救与持续改进提供了新的思路与实践启示。

9.基于预训练语言模型的用户评论情感分析
随着互联网经济发展，文本情感分析在商业智能等领域价值显著。针对传统方法（如 TF-IDF、
Word2Vec）处理复杂语义的局限性，研究预训练模型（如 ERNIE 模型、BERT 模型）在中文情感分析中的优势。通过用
户外卖评论数据集对比实验发现，ERNIE 模型在相同结构的 MLP 分类器中较传统方法显著提升了分类准确率和鲁棒性。
为进一步突破单模型限制，文章提出动态门控双模型融合方法：利用 BERT 的领域适应性与 ERNIE 的通用语义能力，将
BERT 池化层输出经 Sigmoid 函数生成动态权重，实现两模型贡献的实时自适应调节。实验表明，融合模型在精准率、
召回率和 F1 值上均超越单一模型，有效平衡了领域特异性与泛化能力，验证了该方法在中文情感分析任务中的有效性。

对齐评估和安全性评估几个维度对现有工作进行总结，并对大模型的评测基准进行介绍。最后依据现
有研究与潜在的机遇和挑战，对大语言模型评估技术方向和发展前景进行了展望。
